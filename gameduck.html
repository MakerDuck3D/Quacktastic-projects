GAMEDUCK

-Work in progress-
Estimated hardware price15 USD
Measurements (XYZ, cm)10.3 x 15.3 x 2.6

There are lots and lots of awesome open source gaming consoles. So we decided to develop our own, using the most basic parts, thus keeping the price down. The final version comes with joystick, passive buzzer (with a possibility to switch it off), few buttons and fancy LCD display. It should be able to run few games and tools and save the high score of 4 separate players to EEPROM.There are some limiting factors - the Arduino doesn't have much memory and the display doesn't really support any graphics. We are still at the programming stage, but when it's ready, it should include these games:

Stopwatch

Stop the timer at the exact time. Two levels of difficulty.

Calculator

Very simple calculator, nothing more.

Simon

Remember the joystick pattern and repeat it.

Memory game

Find the matching pairs. Single or multiplayer.

Jumpduck

Run as long as you can and don't hit any blocks.

Duckventure

Find the magic earthworm and get it's treasure.

Plug-in from Superducks, provided separately.

Expected improvements for the V2: OLED display, larger memory, internet connection.

Behind the scenes

This project started in the winter of 2025 with a rough idea of how it might work. Code started to be written, but due to some unexpected issues, it was decided to push the coding after a case for the components was printed. That didn't happen for the next 4 months because of a switch from Blender to FreeCAD. The build was, as always, challenging and we ran into many unexpected issues (mostly with soldering and 3D-printing), but we pushed trough and now the only thing left is the coding.
