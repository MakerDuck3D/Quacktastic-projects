DUCK

Cheap and easy to build "smart home" ecosystem





About the project

Main goal of the project DUCK is to make the user's life easier or at least bit more fun.

It uses widespread microcontrollers (Arduino, ESP), some commmon hardware (cheap electronics + M3 screws), and 3D printed parts (optimized for no supports and fit on 180x180 bed). Files for these are on this website to download for free - along with firmware and source model files, allowing for easy customization and improvements. These might be needed, while we aren't professionals and are still learning. But every new release is going to be better, than the previous. So look forward to them and feel free to make yourself a copy of any of these projects.

And have fun doing so!
